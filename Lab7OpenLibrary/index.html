Lab 7: AJAX REST

These examples retrieve JSON data from public APIs and display results without reloading the page. Practice only. No submission required.

Task 1: Wikipedia Suggestions

Enter a word or partial term and click Get Suggestions to retrieve up to five matching Wikipedia article titles. Click a suggestion to open its article.

This task uses jQuery AJAX and demonstrates how to match titles and URLs stored in separate JSON arrays.

    Task 2: ZIP Code Lookup

    Enter a five-digit U.S. ZIP code. Choose Use fetch(), Use $.ajax(), or Use $.getJSON() to retrieve its location information. All three methods request the same data and display the same results.

    This task demonstrates different request methods, nested JSON arrays, and property names containing spaces. All returned places are displayed.

    Task 3: Open Library Search

    Enter a book title or keyword and click Search Books to display up to five matching books with their titles, authors, first publication years, and edition counts.

    This task uses jQuery AJAX and demonstrates processing an array of book records and displaying fallback text for missing information.

    For each task, observe how results update without reloading the page. Try empty input and searches with no matches to examine the messages. Use Developer Tools to inspect requests, JSON responses, and CORS headers.
