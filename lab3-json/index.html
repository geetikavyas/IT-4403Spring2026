Lab 3: JSON

  • Exercise 1: JSON Structure Exploration

    • This exercise helps you understand how information is organized in JSON. You will identify objects, arrays, name/value pairs, and nested structures before writing any code.

  • Exercise 2: Create and Validate JSON

    • This exercise helps you practice writing JSON manually. You will learn how to organize information correctly and identify common JSON syntax errors.

  • Exercise 3: Read JSON Values

    • This exercise helps you access values stored in a JavaScript object. You will also use a loop to display information from an array on a webpage.

  • Exercise 4: Nested JSON Data

    • This exercise helps you work with objects and arrays stored inside another object. You will access student information and use a loop to display the student’s courses.

  • Exercise 5: Weather JSON

    • This exercise helps you read data from a separate JSON file using JavaScript or jQuery. You will select useful weather values and display them as meaningful webpage content.

  • Exercise 6: Movie Information Page

    • This exercise helps you process a more complex JSON file containing nested objects and arrays. You will transform the movie data into a clear and organized webpage.
