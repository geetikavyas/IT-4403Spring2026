Exercise 1: JSON Structure Exploration

I examined the JSON document for the Open Library book record OL7353617M. The main structure is a JSON object containing information about one book.

Main keys

Some of the main keys describe the book's title, publication information, contributors, identifiers, links, and other book details.

Name/value pair

"title": "Fantastic Mr. Fox"

Object

An object uses curly braces and contains related name/value pairs.

{
  "key": "/books/OL7353617M",
  "title": "Fantastic Mr. Fox"
}

Array

An array stores a collection of values inside square brackets.

"publishers": [
  "Puffin"
]

Nested structure

A nested structure places an object or array inside another object.

"first_sentence": {
  "type": "/type/text",
  "value": "Down in the valley there were three farms."
}

Overall organization

The book is represented by one main object. Simple properties store text, numbers, or Boolean values. Arrays store collections, and nested objects provide additional details about related information.
